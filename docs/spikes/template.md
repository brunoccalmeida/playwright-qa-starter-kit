# Spike: the question it answers

- **Issue:** #N
- **Date:** YYYY-MM-DD
- **Timebox:** how long it may take before it stops, with or without an answer

A spike is throwaway work that answers one question before a decision. Its code does not merge; this report does, as `docs/spikes/YYYY-MM-DD-short-name.md`.

## Question

The one question, phrased so that the answer changes what happens next.

## What was tried

Each experiment: the setup (versions, environment, commands) precise enough to repeat it, and its result.

## Findings

What was **observed**, each with its evidence (output, measurement, link). Hypotheses that were not tested stay labelled as hypotheses.

## Answer

The answer to the question, or "not answered" with what is still missing.

## Next step

The decision, issue or ADR the answer feeds.
