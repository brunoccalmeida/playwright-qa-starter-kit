# Architecture Decision Records

Each file records one decision that is expensive to reverse: the context, the decision and its consequences, in the format proposed by Michael Nygard ([Documenting Architecture Decisions](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)). A new record starts as a copy of [template.md](template.md), named `NNNN-the-decision.md` with the next number.

An accepted record is never rewritten. A decision that changes gets a new record that supersedes the old one, so the history of _why_ survives.
